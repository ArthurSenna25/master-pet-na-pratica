Botão de ação do sistema; use `primary` (ouro) para UMA ação principal por tela e `secondary`/`outline` para o resto.

```jsx
<Button size="lg" arrow>Agendar diagnóstico</Button>
<Button variant="outline">Ver método</Button>
<Button variant="inverse">Falar com a Camila</Button> {/* sobre fundo navy */}
```

Variantes: primary, secondary, outline, ghost, inverse. Tamanhos sm(40)/md(48)/lg(56). Estados: hover, active, focus-visible, disabled, loading. Texto do primário é sempre navy (nunca branco, nunca preto).
